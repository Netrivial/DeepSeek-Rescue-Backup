# DeepSeek Rescue Backup

> Неофициальный Userscript для резервного копирования чатов DeepSeek в JSON и Markdown — с возможностью продолжить диалог из бэкапа

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)
[![Version](https://img.shields.io/badge/version-0.5-blue.svg)](deepseek-rescue-backup.user.js)

DeepSeek не даёт официального API для выгрузки истории чатов, а таймауты в веб-клиенте иногда «подвешивают» диалоги так, что к ним трудно вернуться. Этот скрипт решает две задачи:

1. **Спасти** текущий чат — выгрузить его в JSON (полный слепок) и Markdown (человекочитаемый вид, совместимый с Obsidian)
2. **Продолжить** диалог из бэкапа — скрипт собирает историю в промпт и вставляет в поле ввода нового чата

Всё работает **локально в браузере**: данные никуда не отправляются, токен нигде не логируется

## ✨ Возможности

- **Backup** — скачивает текущий чат в JSON и Markdown одним кликом
- **Copy MD** — копирует Markdown в буфер обмена (для быстрой вставки в заметки)
- **Continue** — выбираешь JSON-бэкап, скрипт собирает историю и вставляет в поле ввода нового чата
- **Только активная ветка** — если ты регенерировал ответы, экспортируется именно та ветка, которую ты видишь на экране
- **Thinking-блоки** — размышления модели сохраняются отдельно, в Markdown прячутся в `<details>`
- **YAML frontmatter** — Markdown-файлы сразу индексируются в Obsidian/Logseq
- **Хоткей** — `Ctrl+Shift+E` для быстрого бэкапа
- **Сворачиваемая панель** — не мешает интерфейсу; состояние запоминается

## 🚀 Установка

### Вариант 1: Tampermonkey / Violentmonkey (рекомендуется)

1. Установи расширение: [Tampermonkey](https://www.tampermonkey.net/) (Chrome, Firefox, Edge, Safari) или [Violentmonkey](https://violentmonkey.github.io/)(Chrome, Firefox)
2. Открой [deepseek-rescue-backup.user.js](deepseek-rescue-backup.user.js) и нажми **Raw**
3. Tampermonkey предложит установить скрипт — соглашайся
4. Открой [chat.deepseek.com](https://chat.deepseek.com/), залогинься — в правом нижнем углу появится круглая кнопка `+`

### Вариант 2: Вручную через консоль (без расширения)

1. Открой DeepSeek, нажми `F12` → вкладка **Console**
2. Скопируй весь код из `deepseek-rescue-backup.user.js` и вставь в консоль. Enter
3. Кнопки появятся в правом нижнем углу. Работает, но **не переживёт перезагрузку страницы** — это разовый способ

### Мобильные браузеры

- **Android:** Firefox (полная поддержка Tampermonkey/Violentmonkey) или Edge (через меню расширений)
- **iOS:** сложнее. Можно через Safari + приложение «Userscripts», но без гарантий

## 🎯 Использование

1. Открой любой чат — в URL должен быть `/a/chat/s/<uuid>`
2. **Backup** — скачиваются два файла: `deepseek_2026-11-19_05-14_<название>.json` и `.md`
3. **Copy MD** — Markdown копируется в буфер, вставляй куда хочешь
4. **Continue** — выбери ранее скачанный `.json`, скрипт вставит историю в поле ввода. Проверь и отправь
5. **Ctrl+Shift+E** — быстрый Backup, работает даже когда панель свёрнута

## 🔧 Как это работает

Скрипт использует внутренний API DeepSeek (`/api/v0/chat/history_messages`) и токен из `localStorage`. Активная ветка диалога собирается по цепочке `parent_id` от `current_message_id` — так экспортируется именно то, что видно на экране, без регенераций

**Подробности:**
- JSON содержит поля: `id`, `url`, `title`, `exported_at`, `session` (модель, даты), `messages[]` (роль, контент, `thinking`, timestamp)
- Markdown — YAML frontmatter + заголовки `**User**` / `**DeepSeek**` + `<details>` для `thinking`

## ⚠️ Ограничения и известные проблемы

- **Внутренний API может измениться** в любой момент. Если скрипт перестал работать — скорее всего, DeepSeek поменял эндпоинт или формат. Открой issue, приложи RAW-ответ из консоли
- **Экспортируется только активная ветка.** Если важна история всех регенераций — это не поддерживается (пока)
- **`Export All` пока нет** — только по одному чату за раз
- **Continue — это вставка контекста, не «восстановление сессии».** DeepSeek не позволяет загрузить чат обратно в аккаунт; модель просто получает историю как длинное сообщение
- **Очень длинные чаты** могут упереться в лимит контекста при Continue (128k токенов у DeepSeek V3)

## ❓ FAQ

**— Скрипт не работает, кнопок нет**
Открой консоль (`F12`), проверь, что Tampermonkey включён, скрипт активен, и что ты на `chat.deepseek.com`. Проверь, есть ли ошибки в Console

**— `[Backup] RAW API response: {code: 40003, ...}`**
Проблема с токеном. Попробуй: выйти и войти заново, потом перезагрузить страницу

**— `[Backup] RAW API response: {code: 0, ...}` но сообщений 0**
Скорее всего, ты на главной странице без открытого чата, либо чат пуст. Открой конкретный чат (`/a/chat/s/...`)

**— Continue вставил текст не туда**
Скрипт ищет последний видимый `textarea`. Если DeepSeek изменит вёрстку — может промахнуться. В таком случае контекст попадёт в буфер обмена, вставляй вручную

**— Хочу HTML-экспорт**
Пока не планируется. JSON — мастер-копия, Markdown — для чтения. HTML даёт мало пользы сверх этого
